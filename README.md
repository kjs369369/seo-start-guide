# 검색등록 한 걸음씩

내 사이트를 **구글 · 네이버 · 빙** 검색에 나오게 하는 25단계 가이드 앱입니다.
검색엔진 등록을 한 번도 해본 적 없는 사람이 혼자서 끝까지 갈 수 있도록 만들었습니다.

## 무엇이 들어 있나

| 파일 | 설명 |
|---|---|
| `index.html` | **체크리스트 모드** — 한 화면에 한 단계씩. 진행률 저장, 복사 버튼 |
| `all.html` | **전체 보기 모드** — 검색엔진별 탭, 인쇄·PDF 저장 |
| `data.js` | 25단계 원본 데이터 (여기만 고치면 두 화면에 동시 반영) |
| `templates/robots.txt` | 그대로 복사해 쓰는 robots.txt 견본 |
| `templates/sitemap.xml` | 그대로 복사해 쓰는 sitemap.xml 견본 |

## 특징

- **주소 자동 채움** — 맨 위에 내 사이트 주소를 한 번 넣으면 25단계 전체의 복사 버튼에 자동 반영
- **진행률 저장** — 브라우저에 저장되어 며칠에 걸쳐 나눠서 진행 가능
- **의존성 0** — 빌드 도구·프레임워크·CDN 없음. 파일을 열면 바로 작동
- **다크모드 대응**, 모바일 대응, 인쇄 레이아웃 별도 제공

## 다루는 범위

| 구간 | 단계 | 내용 |
|---|---|---|
| 🎒 준비 | 3 | 주소 확인, 계정 3종, `<head>` 여는 법 |
| 🔵 구글 | 6 | 서치 콘솔 등록 → 소유확인 → 사이트맵 → 색인 요청 |
| 🟢 네이버 | 5 | 서치어드바이저 등록 → 소유확인 → 사이트맵/RSS → 수집 요청 → 진단 |
| 🟣 빙 | 4 | 웹마스터 도구 → 구글에서 가져오기 → 사이트맵/URL 제출 |
| 🏁 마무리 | 5 | robots.txt, sitemap.xml, title/description, 색인 확인, 월간 점검 |

## 로컬에서 보기

```bash
git clone https://github.com/kjs3693693/seo-start-guide.git
cd seo-start-guide
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

파일을 그냥 더블클릭해서 열어도 작동합니다.

## 내용 고치기

`data.js` 의 `STEPS` 배열만 수정하면 됩니다. 각 단계는 이렇게 생겼습니다.

```js
{
  sec: "google",              // ready | google | naver | bing | finish
  title: "단계 제목",
  lead: "한 줄 설명",
  minutes: 3,                 // 예상 소요 시간
  todo: ["할 일 1", "할 일 2"],
  copy: "{{내주소}}",          // 복사 버튼 (선택)
  copyLabel: "복사할 값 설명",
  code: "<meta ... />",       // 코드 블록 (선택)
  codeLabel: "코드 설명",
  links: [{ label: "버튼 이름", url: "https://..." }],
  tip: "막혔을 때 팁"
}
```

`{{내주소}}` 는 사용자가 입력한 주소로 자동 치환됩니다.
